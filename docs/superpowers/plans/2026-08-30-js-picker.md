# helix.picker(方案 C 最小版)实现计划

> **面向 AI 代理的工作者:** 必需子技能:使用 superpowers:subagent-driven-development(推荐)或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框(`- [ ]`)语法来跟踪进度。

**目标:** `helix.picker.define/run` 让插件定义数据源并调起原生 Picker(过滤/滚动/预览/键位全核心),内置插件 `picker.js` 提供 files/grep/buffers/symbols 四源;`helix.read_tree` 补递归文件列表。

**架构:** 核心泛型 `Picker<T,D>` 已有全部机制;新增 `T = PickerRow { cells, payload }` 驱动通道。JS 侧源表(state.rs `with_picker_sources`);`run` 调 items(同步数组或 Promise,异步经 `.then` 续体)→ push `UiRequest::OpenPicker { source }` → term 侧 `apply_ui_requests` 消费建 Picker;Enter 调 JS action、选中调 JS preview(转 FileLocation)。read_tree 照 `glob_async` 的 `spawn_async_op` promise 管道。

**技术栈:** Rust(helix-js boa + helix-term + helix-view)、serde_json、tokio。

**规格:** `docs/superpowers/specs/2026-08-30-js-picker-design.md`(已批准;本计划含 1 处规格微调:items 行支持 `{cells, payload}` 对象分离动作数据——buffers 源需要 id,审查时核对)

```rust
/// 递归列出目录树(先序):目录先行、同级按名排序、depth 限制(Some(n) = 最多 n 层子目录)。
/// 返回 (name, is_dir, path);失败返回 Err 字符串。
fn tree_matches(root: &str, depth: Option<usize>) -> Result<Vec<(String, bool, String)>, String> {
    fn walk(dir: &std::path::Path, cur_depth: usize, depth: Option<usize>, out: &mut Vec<(String, bool, String)>) -> Result<(), String> {
        let mut entries: Vec<_> = std::fs::read_dir(dir)
            .map_err(|e| format!("read_dir('{}'): {e}", dir.display()))?
            .filter_map(|e| e.ok())
            .map(|e| {
                let name = e.file_name().to_string_lossy().into_owned();
                let is_dir = e.file_type().map(|t| t.is_dir()).unwrap_or(false);
                let path = e.path().to_string_lossy().into_owned();
                (name, is_dir, path)
            })
            .collect();
        entries.sort_by(|a, b| b.1.cmp(&a.1).then_with(|| a.0.cmp(&b.0))); // 目录先行,同级按名
        for (name, is_dir, path) in entries {
            out.push((name, is_dir, path.clone()));
            if is_dir && depth.is_none_or(|d| cur_depth < d) {
                walk(std::path::Path::new(&path), cur_depth + 1, depth, out)?;
            }
        }
        Ok(())
    }
    let mut out = Vec::new();
    walk(std::path::Path::new(root), 0, depth, &mut out)?;
    Ok(out)
}

pub(crate) fn js_read_tree(
    _this: &JsValue,
    args: &[JsValue],
    context: &mut Context,
) -> boa_engine::JsResult<JsValue> {
    let path: String = args
        .first()
        .unwrap_or(&JsValue::undefined())
        .try_js_into(context)
        .map_err(|_| JsError::from_opaque(JsValue::from(JsString::from("read_tree: path must be a string"))))?;
    let depth = match args.get(1).and_then(|v| v.as_object()) {
        Some(o) => o.get(JsString::from("depth"), context)?
            .as_number()
            .map(|n| n as usize),
        None => None,
    };
    let (promise, resolving) = JsPromise::new_pending(context);
    let id = crate::state::next_async_id();
    crate::state::with_async_promises(|m| m.insert(id, resolving));
    crate::state::spawn_async_op(id, move || tree_matches(&path, depth), crate::state::AsyncEvent::FsGlob);
    Ok(promise.into())
}
```

**resolve 侧**(照 AsyncEvent::FsGlob 的现有 resolve 处理,找到后把 `Vec<(String,bool,String)>` 转 JS 数组 `[{name,is_dir,path}]`——参照 js_read_dir 的 ObjectInitializer 模式;若是新 AsyncEvent variant 则在事件泵加分支)。

```rust
/// helix.picker.define(name, { columns, items, preview?, action? })
pub(crate) fn js_picker_define(
    _this: &JsValue,
    args: &[JsValue],
    context: &mut Context,
) -> boa_engine::JsResult<JsValue> {
    let name: String = args
        .first()
        .unwrap_or(&JsValue::undefined())
        .try_js_into(context)
        .map_err(|_| JsError::from_opaque(JsValue::from(JsString::from("picker.define: name must be a string"))))?;
    let Some(config) = args.get(1).and_then(|v| v.as_object()) else {
        return Err(JsError::from_opaque(JsValue::from(JsString::from("picker.define: config must be an object"))));
    };
    // 校验 columns:字符串数组
    let columns = config.get(JsString::from("columns"), context)?;
    let columns = columns.as_object().and_then(|o| o.get(JsString::from("length"), context).ok())
        .ok_or_else(|| JsError::from_opaque(JsValue::from(JsString::from("picker.define: columns must be an array"))))?;
    // 校验 items:可调用
    let items = config.get(JsString::from("items"), context)?;
    if !items.is_callable() {
        return Err(JsError::from_opaque(JsValue::from(JsString::from("picker.define: items must be a function"))));
    }
    with_picker_sources(|m| {
        m.insert(name, config.clone());
    });
    Ok(JsValue::undefined())
}

/// helix.picker.run(name):取源 → 调 items(同步数组或 Promise)→ push UiRequest::OpenPicker
pub(crate) fn js_picker_run(
    _this: &JsValue,
    args: &[JsValue],
    context: &mut Context,
) -> boa_engine::JsResult<JsValue> {
    let name: String = args
        .first()
        .unwrap_or(&JsValue::undefined())
        .try_js_into(context)
        .map_err(|_| JsError::from_opaque(JsValue::from(JsString::from("picker.run: name must be a string"))))?;
    let config = with_picker_sources(|m| m.get(&name).cloned())
        .ok_or_else(|| JsError::from_opaque(JsValue::from(JsString::from(format!("picker.run: source '{name}' not defined")))))?;
    let config_obj = config.as_object().unwrap().clone();
    let items_fn = config_obj.get(JsString::from("items"), context)?;
    let undefined = JsValue::undefined();
    let result = items_fn.call(&undefined, &[], context)?;
    // 同步数组 → 立即 push;Promise → .then 续体里 push
    if let Ok(arr) = result.as_object().map(|o| o.is_array()).unwrap_or(false) { /* 数组判定 */ }
    // 简化:统一经 pump_jobs 的续体?不——同步数组直接 push:
    push_open_picker(&name, result, context)?;
    Ok(JsValue::undefined())
}
```

**push_open_picker**(处理同步数组 + Promise 续体):

```rust
fn push_open_picker(name: &str, items_result: JsValue, context: &mut Context) -> boa_engine::JsResult<()> {
    if let Some(promise) = items_result.as_object().and_then(JsPromise::from_object) {
        // async items:注册 .then 续体,resolve 后 push OpenPicker(携带行数据)
        let name = JsString::from(name);
        let name2 = name.clone();
        promise.then(
            Some(closure!(&name2, |_, value, ctx| {
                // value = 行数组;转存 pending items 再 push
                let name: String = name2.to_std_string_escaped();
                let rows = parse_rows(value, ctx)?;
                crate::popup::push_ui_request(crate::types::UiRequest::OpenPicker { source: name, rows: Some(rows) });
                Ok(JsValue::undefined())
            })),
            None,
            context,
        )?;
        Ok(())
    } else {
        let rows = parse_rows(items_result, context)?;
        crate::popup::push_ui_request(crate::types::UiRequest::OpenPicker { source: name.to_string(), rows: Some(rows) });
        Ok(())
    }
}
```

```rust
fn build_columns(names: &[String]) -> Vec<Column<PickerRow, ()>> {
    names.iter().enumerate().map(|(i, name)| {

/// 从 rows + 源名构建并推入 compositor。action/preview 回调经 source 名查 JS 配置。
pub(crate) fn open_picker(cx: &mut Context, source: &str, rows: Vec<RowSpec>, columns: Vec<String>) {
    let options: Vec<PickerRow> = rows.into_iter().map(|r| PickerRow { cells: r.cells, payload: r.payload }).collect();
    let source_owned = source.to_string();
    let picker = Picker::new(
        build_columns(&columns),
        0,
        options,
        (),
        move |_cx: &mut Context, row, _action| {
            helix_js::picker::invoke_action(&source_owned, &row.payload);
        },
    );
    let picker = picker.with_preview(move |_editor: &helix_view::Editor, row: &PickerRow| {
        helix_js::picker::invoke_preview(&source_owned, &row.payload).map(|(path, line)| {
            (PathOrId::Path(path.into()), Some((line, 0)))
        })
    });
    // preview 未定义时 invoke_preview 返回 None → 无预览(核心 show_preview 处理 None)
    cx.push_layer(Box::new(compositor::overlaid(picker)));
}
```

```js
// picker.js — helix.picker 内置源(files/grep/buffers/symbols)
// 用法:init.js 里 helix.load("features/picker.js");然后用 helix.map 绑键位:
//   helix.map("normal", "space-f", () => helix.picker.run("files"));
//   helix.map("normal", "space-g", () => helix.picker.run("grep"));
// 复制本文件即可自定义源(改 items/preview/action)。

// files:当前目录文件树(cwd = hx 启动目录)
helix.picker.define("files", {
  columns: ["name", "path"],
  items: () => helix.read_tree(".").then((entries) =>
    entries.filter((e) => !e.is_dir).map((e) => [e.name, e.path])),
  preview: (row) => ({ path: row[1], line: 0 }),
  action: (row) => helix.open_file(row[1]),
});

// grep:rg 全文搜索(排除 target/.git),预览/跳转定位
helix.picker.define("grep", {
  columns: ["file:line", "text"],
  items: () => helix.run_async("rg -n --no-heading -g '!target' -g '!.git' .").then((out) =>
    out.split("\n").filter(Boolean).map((line) => {
      const [loc, ...rest] = line.split(":");
      return { cells: [loc, rest.join(":")], payload: [loc, rest.join(":")] };
    })),
  preview: (row) => { const [f, l] = row[0].split(":"); return { path: f, line: Number(l) - 1 }; },
  action: (row) => { const [f, l] = row[0].split(":"); helix.open_file(f, { row: Number(l) - 1 }); },
});

// buffers:打开缓冲切换
helix.picker.define("buffers", {
  columns: ["name", "path"],
  items: () => helix.buffers().map((b) => ({ cells: [b.name, b.path || ""], payload: [String(b.id)] })),
  action: (row) => helix.focus_buffer(Number(row[0])),
});

// symbols:文档符号跳转(需 LSP);payload = [name, 起始行],action 经 set_cursor 跳当前文档
helix.picker.define("symbols", {
  columns: ["name", "kind"],
  items: async () => {
    const syms = await helix.lsp.document_symbols() || [];
    const flat = [];
    (function walk(s) {
      for (const x of s) {
        flat.push({ cells: [x.name, x.kind], payload: [x.name, String(x.range.start.line)] });
        if (x.children) walk(x.children);
      }
    })(syms);
    return flat;
  },
  action: (row) => helix.set_cursor(Number(row[1]), 0),
});
```

**注意**:symbols 源的 action 需要 range 数据(document_symbols 返回带 range,但行数据里只放了 name/kind)——把 range 塞 payload:`{cells:[name,kind], payload:[name, range 起始行]}`;action 用 `helix.set_cursor`/跳转。**最小版**:payload 放起始行,action 调 `helix.set_selection` 或已有跳转 API(查 plugin-api 的 set_cursor)。若 API 不足,symbols 源标注 TODO 留后续,不阻塞本批次。
