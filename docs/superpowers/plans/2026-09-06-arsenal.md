# arsenal(mason 式管理市场界面)实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** `:arsenal` 打开 mason 式居中市场窗管理 LSP/DAP/linter/formatter：搜索/分类/行状态、Enter 动作菜单、i 信息弹窗、tab 多选批量、后台执行带阶段与真实下载百分比进度反馈；能力全部复用 server manager 后端。

```rust
/// 下载进度聚合:按字节阈值或时间间隔回调;finish 必 flush。
pub struct ProgressAgg<'a> {
    throttle_bytes: u64,
    throttle_dur: std::time::Duration,
    cb: &'a mut dyn FnMut(u64, Option<u64>),
    last_bytes: u64,
    last_at: std::time::Instant,
}
impl<'a> ProgressAgg<'a> {
    pub fn new(
        throttle_bytes: u64,
        throttle_dur: std::time::Duration,
        cb: &'a mut dyn FnMut(u64, Option<u64>),
    ) -> Self {
        ProgressAgg { throttle_bytes, throttle_dur, cb, last_bytes: 0, last_at: std::time::Instant::now() }
    }
    pub fn add(&mut self, bytes: u64, total: Option<u64>) {
        let now = std::time::Instant::now();
        if bytes >= self.last_bytes + self.throttle_bytes
            || now.duration_since(self.last_at) >= self.throttle_dur
        {
            self.last_bytes = bytes;
            self.last_at = now;
            (self.cb)(bytes, total);
        }
    }
    pub fn finish(&mut self, bytes: u64, total: Option<u64>) {
        self.last_bytes = bytes;
        (self.cb)(bytes, total);
    }
}
```

```rust
/// 在独立线程执行的单步任务(install/update/remove/unmanage)。
/// progress(name 固定,由调用方填充)收到阶段与字节事件。
pub struct TaskOutcome { pub ok: bool, pub msg: String }

pub fn run_task(
    op: &str,
    name: &str,
    version: Option<&str>,
    mut progress: impl FnMut(&str, Option<u64>, Option<u64>) + Send,
) -> TaskOutcome {
    // 每个 op 先重读 config(保持与 :server 一致)
    let _ = apply_server_config(disk_server_manager_table().as_ref());
    let out = (|| -> Result<String> {
        match op {
            "install" => {
                let spec = registry::get(name).ok_or_else(|| anyhow!("unknown server '{name}'"))?;
                match availability(name) {
                    Availability::Managed => return Err(anyhow!("'{name}' 已安装,用 update")),
                    Availability::Local(p) => return Err(anyhow!("'{name}' 本地已可用({}),无需安装", p.display())),
                    Availability::Missing => {}
                }
                if !spec.is_installable() {
                    return Err(anyhow!("'{name}' 下载源未配置(registry 缺 url)"));
                }
                let ver = match version.map(str::to_string).or_else(|| spec.version.clone()) {
                    Some(v) => v,
                    None => return Err(anyhow!("'{name}' 配方未给 version;传入 version 或 config 补")),
                };
                progress("下载中", None, None);
                install(name, &ver)?;
                progress("写入配置", None, None);
                rewrite_languages_toml()?;
                Ok(format!("installed '{name}' {ver}"))
            }
            "update" => { /* availability Managed 才可; 版本取参或 spec.version; 调 update+rewrite; Err 否则 */ }
            "remove" => { /* availability Managed → server_manager::remove(name)?; Err 否则(含 local 指引 unmanage) */ }
            "unmanage" => {
                match availability(name) {
                    Availability::Local(_) => {
                        let on = !ignored_local().contains(&name.to_string());
                        set_ignored(name, on)?;
                        rewrite_languages_toml()?;
                        Ok(if on { format!("'{name}' 已停用挂接") } else { format!("'{name}' 已恢复挂接") })
                    }
                    _ => Err(anyhow!("'{name}' 非本机已有,unmanage 仅对 local 有效")),
                }
            }
            other => Err(anyhow!("unknown task op '{other}'")),
        }
    })();
    match out {
        Ok(msg) => TaskOutcome { ok: true, msg },
        Err(e) => TaskOutcome { ok: false, msg: format!("{e:#}") },
    }
}
```

说明:update/remove 分支按上注释实现(对照 `typed.rs` server_op 的既有判定文案保持一致性即可);下载字节进度需在 `install` 内部产生——为此把 `install(name,ver)` 的低层下载接到进度,最小做法:任务 2 暂只推阶段事件,真实字节进度放任务 3(见下),`run_task` 的 `progress(name?)` 回调参数 `(&str 阶段, Option<u64> bytes, Option<u64> total)` 先传 `("下载中",None,None)`;任务 3 再让 install 路径携带字节回调。

```js
function visible() {

  return S.rows.filter((r) => {
    if (S.kind !== "all" && r.kind !== S.kind) return false;
    if (S.kind === "installed" && !r.installed) return false;

    if (!f) return true;
    return (r.name + " " + r.languages.join(" ") + " " + r.description).toLowerCase().includes(f);

function status_text(r) {
  if (r.busy) return r.busy;                    // 进度覆写(见 M4)

function row_el(r, i, h) {
  const sel = i === S.sel;
```
