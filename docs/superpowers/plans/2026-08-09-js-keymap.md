# JS 键位绑定实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 让 JS 插件绑定键位：`helix.map(mode, key, command)`，command 为内置/插件命令名或 JS 回调，运行时注入实时 keymap。

**架构：** 复用既有接线。helix-js 增加 `UiRequest::MapKey` 变体 + `js_map` 原生函数（回调自动注册为 `__mapped_<N>` 插件命令）；helix-term 把 keymap 的 DynAccess 从 config Map 换成全局 `ArcSwap` 槽（`OnceLock<ArcSwap<HashMap<Mode, KeyTrie>>>`），`apply_ui_requests` 在命令分发 / `:plugin-load` / 启动加载三个点消费 MapKey（解析键序列 → 构建 KeyTrieNode 链 → merge_keys → store）；`MappableCommand::execute` 的 Typable 分支在静态表 miss 时回退插件命令注册表（提取共享 `run_plugin_command`）。

**技术栈：** 既有 helix workspace。无新依赖（arc-swap 已是 workspace 依赖）。

```rust
fn keymap_registration() {
    let _guard = TEST_LOCK.lock().unwrap();
    init();

    // 字符串命令 → MapKey 入队
    load_script(r#"helix.map("normal", "gd", "goto-def");"#).unwrap();

    match &reqs[0] {

            assert_eq!(key, "gd");
            assert_eq!(command, "goto-def");

        other => panic!("expected MapKey, got {other:?}"),
    }

    // 回调 → 注册 __mapped_N + MapKey 入队
    load_script(
        r#"
        helix.map("insert", "C-n", () => { helix.echo("cb"); });
        "#,
    )
    .unwrap();
    let reqs = take_ui_requests();
    assert_eq!(reqs.len(), 1);
    let command = match &reqs[0] {
        UiRequest::MapKey { command, .. } => command.clone(),
        other => panic!("expected MapKey, got {other:?}"),
    };
    assert!(command.starts_with("__mapped_"), "command: {command}");
    // 注册的命令可以运行（与普通插件命令同机制）

    assert!(load_script(r#"helix.map("bogus", "x", "y");"#).is_err());
```

```rust
const KEYMAP_MODES: [&str; 3] = ["normal", "insert", "select"];

fn js_map(_this: &JsValue, args: &[JsValue], context: &mut Context) -> boa_engine::JsResult<JsValue> {
    let mode: String = args.first().unwrap_or(&JsValue::undefined()).try_js_into(context)?;
    if !KEYMAP_MODES.contains(&mode.as_str()) {
        return Err(JsError::from_opaque(JsValue::from(JsString::from(format!(
            "helix.map: unknown mode '{mode}'"
        )))));
    }
    let key: String = args.get(1).unwrap_or(&JsValue::undefined()).try_js_into(context)?;
    if key.is_empty() {
        return Err(JsError::from_opaque(JsValue::from(JsString::from(
            "helix.map: key must not be empty",
        ))));
    }
    let command_arg = args.get(2).cloned().unwrap_or(JsValue::undefined());

    // 函数 → 注册为隐藏插件命令 __mapped_N
    let command: String = if command_arg.as_callable().is_some() {
        let id = NEXT_MAP_ID.with(|c| { let v = c.get(); c.set(v + 1); v });
        let name = format!("__mapped_{id}");
        REGISTRY.get().unwrap().lock().insert(name.clone(), command_arg);
        name
    } else {
        command_arg.try_js_into(context)?
    };

    UI_REQUESTS.get().unwrap().lock().unwrap().push(UiRequest::MapKey { mode, key, command });
    Ok(JsValue::undefined())
}
```

> 注意：`REGISTRY` 是 thread_local（RefCell）还是全局 Mutex——以当前代码实际结构为准（既有 `js_register_command` 怎么插入的就怎么插）。`try_js_into::<String>` 对非字符串会报错（42 传 command 时走字符串转换报错）。mode/key 的 `try_js_into` 同样对数字报错。

```rust
/// 消费插件 UI 请求：MapKey 注入 keymap；OpenPopup 在无 compositor 的上下文跳过
fn apply_ui_requests(reqs: Vec<helix_js::UiRequest>, cx: Option<&mut compositor::Context>) -> anyhow::Result<()> {
    for req in reqs {
        match req {
            helix_js::UiRequest::OpenPopup { id } => {
                if let Some(cx) = cx {
                    let popup = ui::Popup::new("plugin-popup", ui::PluginPopup::new(id)).auto_close(false);
                    job::dispatch_blocking(move |_editor, compositor| {
                        compositor.replace_or_push("plugin-popup", popup);
                    });
                }
            }
            helix_js::UiRequest::MapKey { mode, key, command } => {
                apply_plugin_keymap(&mode, &key, &command)?;
            }
        }
    }
    Ok(())
}

/// 把单个键位绑定注入运行时 keymap
fn apply_plugin_keymap(mode: &str, key: &str, command: &str) -> anyhow::Result<()> {
    use helix_view::{Mode, input::KeyEvent};
    use std::str::FromStr;

    let mode = match mode {
        "normal" => Mode::Normal,
        "insert" => Mode::Insert,
        "select" => Mode::Select,
        other => bail!("unknown mode '{other}'"),
    };
    // 解析键序列：按空白分词 → 每 token 先整体解析（"C-n"），失败则逐字符（"gd"）
    let mut keys: Vec<KeyEvent> = Vec::new();
    for token in key.split_whitespace() {
        match KeyEvent::from_str(token) {
            Ok(k) => keys.push(k),
            Err(_) => {
                for ch in token.chars() {
                    keys.push(KeyEvent::from_str(&ch.to_string()).map_err(|_| {
                        anyhow!("cannot parse key '{token}'")
                    })?);
                }
            }
        }
    }
    if keys.is_empty() {
        bail!("empty key sequence");
    }

    // 构建 KeyTrieNode 链：叶子 = MappableCommand::Typable
    let cmd = MappableCommand::Typable {
        name: command.to_string(),
        args: String::new(),
        doc: String::new(),
    };
    let mut trie = KeyTrie::Leaf(KeymapResult::MappableCommand(cmd));
    for key in keys.into_iter().rev() {
        let mut map = indexmap::IndexMap::new();
        map.insert(key, trie);
        trie = KeyTrie::Node(KeyTrieNode::new("plugin-map", map));
    }
    let mut delta = std::collections::HashMap::new();
    delta.insert(mode, trie);

    let mut current = KEYMAPS.get().expect("KEYMAPS initialized").load().as_ref().clone();
    crate::keymap::merge_keys(&mut current, delta);
    KEYMAPS.get().expect("KEYMAPS initialized").store(std::sync::Arc::new(current));
    Ok(())
}
```

> 注意：`KEYMAPS` 是 application.rs 的 static——typed.rs 引用需 `crate::application::KEYMAPS`（若 static 是 pub(crate)）。`KeymapResult`/`KeyTrieNode`/`KeyTrie`/`MappableCommand` 的导入路径以编译为准（keymap.rs / commands.rs）。`indexmap` 已是 workspace 依赖（helix 大量使用）。若 `KEYMAPS.get()` 在测试环境未初始化（集成测试走 `Application::new`，会初始化——确认 get_or_init 在 new 里执行）。

d) 三个调用点替换为 `apply_ui_requests`：
- 命令分发 `Ok(true)` 分支：现有 `for req in helix_js::take_ui_requests() { match OpenPopup ... }` → `apply_ui_requests(helix_js::take_ui_requests(), Some(cx))?;`
- `:plugin-load` 命令：现有 drain messages 后追加 `apply_ui_requests(helix_js::take_ui_requests(), Some(cx))?;`
- 启动加载（application.rs 插件循环）：现有 `helix_js::take_messages()` 处理处追加 `let _ = apply_ui_requests(helix_js::take_ui_requests(), None);`（无 compositor，只应用 MapKey）
