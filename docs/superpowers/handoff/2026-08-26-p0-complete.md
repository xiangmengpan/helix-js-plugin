## 关键架构事实(新会话必读)

- **泵循环**:helix-term/src/application.rs 340 行附近,顺序:term/async 事件 → LSP 结果 resolve → pump_jobs → take_edits/take_messages。早退路径已覆盖 LSP 请求
- **Promise 管道**:JS 侧 `JsPromise::new_pending` + `with_*_promises` map;结果经 WakeSender channel 回主线程 `resolve_*` 兑现;`pump_jobs()` 驱动 .then/await 恢复
- **register_command 不 await async fn**(run_command 同步 call),但 boa async fn 执行到首个 await 后由 pump_jobs 驱动恢复——可用
- **dispatch_blocking 是排队异步**(名字误导):async 命令里 open_file 定位下一轮事件循环生效
- **测试环境默认禁 LSP**(helpers.rs test_editor_config `lsp.enable: false`)——真 LSP 测试需 `cfg.editor.lsp.enable = true` 覆盖
- **SDD 工作区**:`.superpowers/sdd/2026-08-26-js-lsp-request/`(含设计/计划/审查报告/账本)、`.superpowers/sdd/2026-08-26-js-input-completion/`
