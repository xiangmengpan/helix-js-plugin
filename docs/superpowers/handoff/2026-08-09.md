## 项目本质

**魔改 helix 编辑器（Rust），嵌入 JS 插件系统**。基分支 master（本地 fork，无远端推送需求）。

## 架构分层

```
helix-js/           新 workspace member：JS 运行时（boa_engine 0.21.1）
  - thread_local 引擎（boa Context !Send）＋泄漏容器模式（防 teardown 崩溃）
  - 全局队列：MESSAGES / UI_REQUESTS / TERM_EVENTS(WakeSender) / ASYNC_EVENTS / NODE_HANDLERS
  - 36 个 helix.* API 函数 + ctx 对象 + 5 事件 + 6 组件节点
helix-term/         host 接线
  - compositor：main_tree(布局树) + layers(瞬态覆盖层)
  - ui/layout.rs：LayoutNode(Split/Leaf 二分树) + LayoutTree（组件表/焦点/缩放/序列化）
  - ui/plugin_popup.rs / plugin_panel.rs / plugin_terminal.rs（vte 网格）/ comp_layout.rs（布局引擎+DiffRenderer）
  - commands/typed.rs：apply_ui_requests（drain 所有 UiRequest）
```

## 已知问题

- **并行 flake**：全量 integration 偶发 1-2 失败（plugin_keymap/plugin_events 窄竞态、plugin_theme 并行干扰、上游 SIGABRT）——隔离重跑即绿
- **终端叶子吞键**：split 出终端后它消费所有按键，`:命令` 进不了命令行——需先 focus(0)
- **死代码警告**：plugin_panel/plugin_terminal 的 side/size/area_for/layout_panels 是旧条带布局遗留（树取代），clippy 有警告未清
- **面板/终端模式 API**（set_terminal_mode 的 fullscreen/minimized/floating）在树模型下映射粗糙（fullscreen≈zoom）
