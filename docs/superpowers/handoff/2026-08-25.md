## 一、项目定位

基于上游 Helix 的 fork,三大改造:

1. **JS 插件系统**:内置 boa 引擎,插件可注册命令/渲染 UI/监听事件/接管快捷键提示(~70 API + 14 事件)
2. **zellij 式窗口模式**:全局 C-w 窗口管理,任何叶子焦点可用(Rust compositor 层)
3. **终端增强 + 插件化视图**:原生终端面板、JS 组件视图层

1. **insert 光标消失**:编辑器在布局树 main_tree,但 compositor.cursor 只查 layers → bar/underline 硬件光标永远 Hidden。修:LayoutTree::cursor 转发活动叶子光标(commit `5e393a595`)
2. **光标坐标偏移**:叶子 rect 相对 tree_area(tabbar/底部 UI 让行),补 tree_area 原点(commit `c403bef06`)
3. **光标 row/col 交换**(关键 bug):`Position::new(row, col)` 参数序错误 → 光标恒在"行号宽度行"、回车右移。已修(commit `6705d08c2`)并有回归测试 `cursor_position_not_swapped`
