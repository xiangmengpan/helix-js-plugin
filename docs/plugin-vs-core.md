# 该插件化 vs 该留核心 —— 判定清单

> **一句话总则**:插件决定**「什么」**,核心负责**「怎么把它画到屏幕上、且不出错」**。

本清单不是原则推演 —— **每一条判据后面都挂着一条本项目的实测数字或一次真实事故**
(来源:2026-10 的 picker / 布局 / 模式三轮改造,见文末「证据」)。

---

## 一、三道闸门(任一答「是」⇒ 该留核心)

| 闸门 | 问法 | 判据 |
|---|---|---|
| **G1 是否在每帧路径上?** | 它每帧都被调用吗? | 是 ⇒ **默认留核心**。实测:每帧 JS 渲染 picker = **≈3.2 ms** = 60fps 预算的 **19.2%** |
| **G2 它是否承载不变量?** | 比例 / 焦点 / 事件路由 / 资源清理 / 几何一致性 | 是 ⇒ **机制留核心**,只把**决策**外移。实例:`move_panel` 搬走后**丢了比例** |
| **G3 是否已有一份插件侧实现?** | 别处是否已有同样功能 | 是 ⇒ 先**消除重复**,再谈搬运。实例:`files` 源曾有**两套**实现(核心 `Space f` + 插件源) |

## 二、分类判定表(用真实例子标定)

| 对象 | 判定 | 依据 |
|---|---|---|
| **有哪些源**(files / grep / buffers / symbols) | ✅ **插件** | 纯决策,打开时一次 —— **已是现状** |
| **过滤 / 排序 / 评分** | ✅ **插件** | 决策;不在每帧渲染路径 |
| **行内注记 / 图标 / git 状态** | ✅ **插件**(按 picker 逐个开) | 核心**画不出** ⇒ 只有这种才值得动渲染 |
| **新增一类 picker** | ✅ **插件** | 框架机制已在核心 |
| **通用列表的排版与绘制** | ❌ **核心** | G1:JS 版只是把核心策略**重写一遍**(CJK 宽度 / 主题色 / 选中标记) |
| **`Picker<T,D>` 框架(窗口 / 匹配 / 预览)** | ❌ **核心** | G2:框架承载生命周期与不变量 |
| **分屏 / 浮窗 / 堆叠的几何** | ❌ **核心** | G2:几何一致性(堆叠改用旁表表示以避开 ~67 处匹配点) |
| **状态栏内容** | ✅ **插件**(可整体替换) | 已是现状;核心保留上游默认作 fallback |
| **模式机(模式栈 / 前缀)** | 机制 ❌ 核心 / 策略 ✅ 插件 | 机制 = 模式栈;策略 = 每个模式有哪些键(插件可推) |
| **终端模拟** | ❌ **核心** | 它是**能力**,不是策略 |

## 三、四条红线(每条对应一次真实事故)

| 红线 | 事故 |
|---|---|
| **R1 每帧路径引 JS** | 实测「响应慢 10 多秒」;另测出 3.2 ms/帧 |
| **R2 搬走「承载不变量」的东西** | `move_panel` 搬出核心后**丢了面板比例**,修完才恢复 |
| **R3 留两套实现** | `Space f` 的核心遍历 vs 插件的 `files` 源 ⇒ 必然漂移 |
| **R4 把「搬走但没接线」当完成** | 桩命令 / 文档自称「未接线」/ 默认渲染器注册了却因**未同步运行副本**而未生效 |

## 四、落地流程(从最便宜、零风险的一端开始)

```
① 只读暴露:先用只读 API 把数据交给插件(picker_state / layout 快照)
   ⇒ 零行为变化,且能**证伪**「插件真的需要它」
② 插件决定:源 / 格式 / 键位 / 默认值(打开时一次 ⇒ 免费)
③ 核心留默认:默认实现**不删**,当 fallback + 性能最优路径
④ 量代价:基准 + 真机各测一次(不量就上 = 3.2ms 或 10 秒)
⑤ 最后才动渲染:且**按实例**开(哨兵 id=0 只留给「确实要全局」的场合)
```

## 五、两难时的默认答案

> **先做 ①「只读暴露」** —— 最便宜、零回归,且能把「我猜插件需要它」变成「有证据要它」。
> 若做完①发现插件只是在**重写**核心已有的策略 ⇒ **停手**。
> (这正是 picker 通用渲染的实况:实测判**否定**。)

## 六、速查

```
Q1 每帧?          是 → 核心
Q2 承载不变量?    是 → 机制留核心,决策给插件
Q3 已有两份实现?  是 → 先合并,再判定
以上皆否          → 插件 ✓(顺手确认:核心留 fallback + 代价量过)
```
