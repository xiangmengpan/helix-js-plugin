## 已知问题 / 边界（诚实标注）

- **选择复制/鼠标/组合字符**：终端暂不支持（标注为后续）
- **C-\ 是单键切换**（lazyvim 是 C-\ C-n 双键）；插件命令**无参数**（`:term-close` 只能关浮动单例或最近的，
  要按 id 关需改 run_plugin_command 传 rest 或另做）
- **全量 integration 偶发并行 flake**（handoff 已知；隔离重跑即绿）；plugin_theme 测试已加串行锁
- **terminal.js 依赖 Unix pty**（Windows 不可用，但用户在 Windows 环境跑说明其环境有 pty 支持，可能是 WSL/容器）
- **statusline replace 模式**：中区宽度 = 视口 - 左 - 右（整除舍入），内容超区截断；段间 gap 固定 1 空格
- **icons.js 的 nerd font 码点**：主流 devicons 确定，个别（git 状态）可能随字体版本偏移——表可自行改
